# The Culinary Guild

The Culinary Guild is an agentic culinary platform that combines:

- Guild Path ingredient discovery
- Kitchen Trials challenge mode
- Otaku Culinary Guild anime-inspired cooking
- Recipe generation and flavor intelligence
- Cultural cuisine systems and prestige editorial experiences

## Apps

- `apps/web` — Next.js frontend
- `apps/api` — FastAPI backend

## Packages

- `packages/prompts` — agent prompt templates
- `packages/schema` — database schema and SQL

## Core Features

- Scan an ingredient and identify it
- Warn users about potentially toxic plants, flowers, and mushrooms
- Generate recipes and pairings
- Infer anime food styles from a series title
- Run challenge-based cooking journeys through Kitchen Trials
